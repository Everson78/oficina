# Projeto Banco de Dados Oficina Mecânica

Projeto desenvolvido como parte do desafio de Banco de Dados da DIO.

## Objetivo

Criar um banco de dados relacional para gerenciamento de uma oficina mecânica, desde a modelagem lógica até a implementação em MySQL.

O sistema permite controlar clientes, veículos, equipes, mecânicos, ordens de serviço, serviços realizados e peças utilizadas.

## Tecnologias utilizadas

- MySQL
- MySQL Workbench

## Conceitos aplicados

- Modelagem relacional
- Chaves primárias (PK)
- Chaves estrangeiras (FK)
- Relacionamentos 1:N
- Relacionamentos N:N
- Constraints
- Consultas SQL

## Entidades

- Cliente
- Veículo
- Ordem de Serviço
- Mecânico
- Equipe
- Serviço
- Peça

## Consultas realizadas

Foram desenvolvidas queries utilizando:

- SELECT
- WHERE
- JOIN
- GROUP BY
- HAVING
- ORDER BY
- Funções de agregação
